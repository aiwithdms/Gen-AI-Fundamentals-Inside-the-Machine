Token galaxy: how a model sees meaning

Inside a model, every word becomes a point in space. Words used in similar ways land close together. This is a simplified 3D picture; real models use hundreds or thousands of dimensions.

1. Look
Each colour is a group of related words.
2. Drag
Swipe or drag to turn the galaxy around.
3. Tap a word
Lines show its three closest neighbours.

2.3 How ChatGPT-type AI works

Prompt → Tokens → Model → Prediction → Response. Type a prompt, then press Run.

Tokens: the text split into pieces, each with a number ID
Press Run to begin.
Model: billions of parameters score every possible next token
Prediction: the most likely next tokens
Response: one token is chosen, added to the text, and the loop repeats
